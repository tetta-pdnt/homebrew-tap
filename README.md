# Homebrew Tap

Install [SARA TUI](https://github.com/tetta-pdnt/sara-tui).

```sh
brew install tetta-pdnt/tap/sara-cli tetta-pdnt/tap/sara-tui
```

Homebrew installs SARA CLI and Leaf as dependencies. Run `sara-tui` from a directory containing `sara.toml` or pass `--project /path/to/project`.

SARA CLI and SARA TUI are built from source. On macOS, building requires the Command Line Tools version supported by [Homebrew](https://docs.brew.sh/Installation).
